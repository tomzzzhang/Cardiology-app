## Required before merge

### 1. Make `docs/` governance both effective and usable

The current guard exits successfully whenever `docs/` is absent on the base commit. Because `main` is empty, it does not protect any `docs/` content introduced anywhere in PR #1. After this PR merges, the same guard reverses into a blanket ban on every future `docs/` change, including the planning session's legitimate schema-v1 synchronization required by `WORKFLOW.md`.

Add a tightly controlled maintainer/planning-doc sync route, while preserving the worker prohibition. The initial import must be explicitly treated as reviewed rather than implicitly trusted by the guard.

### 2. Protect `main` and gate Pages on the full CI result

The live repository has no branch protection or ruleset. Pages runs independently on every push to `main` and does not wait for typecheck, lint, unit, visual, or repository-guardrail jobs. An accidental direct push can therefore publish a build that failed the main quality suite.

Require PRs and the four CI jobs for `main`, block force-push/deletion, and make deployment depend on the successful full CI workflow (or reproduce the complete gate in the deploy workflow).

### 3. Encode the required two-role clinical vetting state

Schema v0 changed `vetter` to `vetters[]`, but a single arbitrary vetter still satisfies the schema. The clinical source documents require a fellow plus an attending before a view is considered vetted. Encode the required role composition and add positive and negative tests. Keep names/identity consent separate from the role requirement.

### 4. Validate asset semantics, not only references

The validator checks that `mesh_node` and voxel assets are named, but it does not confirm that a referenced glTF/GLB node exists or that raw-u8 voxel label values are represented in the label table. A pack can therefore pass CI and fail or silently mislabel at runtime.

For supported Wave 1 formats, validate glTF/GLB node references and external-resource policy. For `raw-u8`, reserve/document background value `0` and reject undeclared non-background values. It is acceptable to leave KTX2 semantic inspection as an explicitly tracked technical-slice gap.

### 5. Reject impossible orientation frames

The orientation object accepts repeated axes and handedness claims inconsistent with the axis mapping. Require a signed permutation of the three anatomical axes and verify that the declared handedness matches the resulting frame. Add invalid-frame tests.

### 6. Reconcile the echo formula before Wave 1b is dispatched

`docs/build_plan.md` specifies:

`scatterer × PSF × specular + boundary_reflection`

`contracts/echo-renderer.md` specifies:

`scatterer × PSF + specular + boundary_reflection`

Workers are told that contracts are immutable source-of-truth files, so this disagreement must be resolved by planning/clinical intent before implementation starts.

### 7. Close path-validation escapes

`AssetPath` rejects literal `../`, but currently permits equivalent or ambiguous forms such as backslashes, encoded traversal, drive-like paths, queries, and fragments. Normalize once and reject backslashes, schemes/drive prefixes, query/fragment text, encoded traversal, absolute paths, and empty segments. Apply the same boundary to runtime-generated pack IDs/URLs and add adversarial tests.
